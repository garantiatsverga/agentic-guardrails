Загрузка документов

Допустимые форматы: PDF, TXT. Все файлы должны относиться к одной заявке: анкета + финотчётность + описание бизнеса. Если загрузить файлы разных заявок, поля будут взяты из первого файла, где они встретились.
Обязательное поле (§4.1).

Как это работает

Загрузка → извлечение (pdfplumber) → валидация (HookBus) → эскалация (AutonomyLadder) → JSON для скоринга. Внешние системы (БКИ, ФНС, ЕГРЮЛ) заменены моками — спринт 2.
